**Step 1 — Edit `backend/app/controllers/v1/domains_controller.rb`:** add the `lookup` method INSIDE the existing class, AFTER the `check` method (around line 21, before the final two `end` keywords for the class and module). Do NOT modify the existing `check` action or `skip_before_action` line.

Add this exact method:
```ruby
    # GET /v1/domains/lookup?domain=X
    # DMOD-13 — public, unauthenticated.
    # Returns { domain: <primary> } for the brokerage owning the queried (routable) domain.
    # 404 if domain not found OR domain is decommissioned OR brokerage has no primary.
    def lookup
      domain_param = params[:domain].to_s.strip.downcase
      return render json: {error: "domain param required"}, status: :bad_request if domain_param.blank?

      domain_record = BrokerageDomain.routable.find_by(domain: domain_param)
      return render json: {error: "not found"}, status: :not_found unless domain_record

      primary = domain_record.brokerage.brokerage_domains
        .routable
        .find_by(is_primary: true)
      return render json: {error: "no primary domain"}, status: :not_found unless primary

      render json: {domain: primary.domain}, status: :ok
    end
```

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-20.03-01 | Information Disclosure | GET /v1/domains/lookup | mitigate | Response body returns only the brokerage's primary domain name — no brokerage ID, name, plan, owner, or membership data leaks. Task 1 acceptance criteria assert the response body shape. |
| T-20.03-02 | Information Disclosure | GET /v1/domains/lookup enumeration | accept | Endpoint is INTENDED to be public (DMOD-13). | T-20.03-03 | Tampering / Injection | `domain` parameter | mitigate | Parameter is normalized via `.to_s.strip.downcase` and used in a parameterized `find_by(domain: ...)` query — no SQL injection vector (ActiveRecord escapes parameters). |
| T-20.03-04 | Denial of Service | Unauthenticated endpoint subject to spam | accept | Single DB index lookup per request (brokerage_domains has a unique partial index on `domain`). Rails middleware + reverse proxy rate limiting (project-level concern) is the standard mitigation. v1.5 explicitly excludes per-endpoint rate limiting. |
