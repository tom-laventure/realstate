## v1.2 Requirements — Final Status

### Data Layer

- [x] **MAP-01**: Listings have geocoded coordinates (lat/lng) stored server-side — sourced from RETS/MLS feed on import, or geocoded from address as fallback
  - **Outcome:** Validated in Phase 8. `decimal(10,6)` lat/lng + `geocoding_failed` on `listing_details`. `GeocodingService` (Nominatim) + `GeocodeListingsJob` (retry/discard) + `geocode:backfill` rake task. RETS/MLS direct ingestion deferred (D-06).

### Group Dashboard Map

- [x] **MAP-02**: Group dashboard renders an interactive Google Maps panel showing a pin for each listing in the group
  - **Outcome:** Validated in Phase 9. Implemented with Mapbox GL JS (react-map-gl) instead of Google Maps — same visual contract. `GroupMapPanel` renders pins for all geocoded listings.

- [x] **MAP-03**: Group dashboard map updates its pins in real time when the active filter set changes — only filtered listings appear as pins
  - **Outcome:** Validated in Phase 9. Coordinates endpoint mirrors full filter param set from `GroupEstatesQuery`. `keepPreviousData: true` prevents pin flash during filter refetch.

- [x] **MAP-05**: Listings in close geographic proximity are grouped into a cluster pin; expanding the cluster reveals individual listing cards
  - **Outcome:** Validated in Phase 9. `use-supercluster` with `radius: 75, maxZoom: 20`. Cluster click → zoom-in; at max zoom → `GroupMapClusterPopup` with per-listing rows.

### Listing Detail Map

- [x] **MAP-04**: The individual listing detail page shows an embedded Google Maps section with the property's location pinned
  - **Outcome:** Validated in Phase 10. Implemented with Mapbox GL JS. `EstateLocationMap` single-pin component between summary card and section tabs. Absent when coordinates are null.

### Pin Interaction

- [x] **MAP-06**: Clicking any listing pin opens a popup card displaying: hero photo, address, price, bed/bath count, sqft, and a "View details" link
  - **Outcome:** Validated in Phase 9. `GroupMapPinPopup` delivers all fields. Hero image falls back to `images[0]` when `hero_image_url` is null. Cluster popup (`GroupMapClusterPopup`) shows address + price rows with arrow links.
