<objective>
Fix two root-route edge cases so unauthenticated users always land on the login page — never a 404 or blank screen.

**ROUTE-01:** Main domain `/` currently falls through to the `*` wildcard and renders `NotFound`. Fix: add an index route inside `MainDomainOnly`'s children that redirects to `/dashboard`. The existing `portalDashboard` route at `/dashboard` already wraps itself in `ProtectedRoute`, so an unauthenticated user lands on `/auth/login` via the standard auth guard flow.

**ROUTE-02:** Subdomain `/` is guarded by `PrimaryDomainRedirect`, which performs an async domain-lookup API call and renders `null` (blank screen, D-02) while in flight — before `ProtectedRoute` can redirect to login. Fix: add an `isAuthenticated()` check at the top of `PrimaryDomainRedirect`'s `useEffect` so unauthenticated users skip the domain lookup entirely and `ProtectedRoute` redirects them immediately.

Both fixes are surgical: 1–2 lines each, no structural refactor.
</objective>

import { isMainDomain } from '@/helpers/domain'

**Step 2 — Add auth check inside the `useEffect`, extending the existing early-return guard:**

Find the existing early-return block inside `useEffect`:
```typescript
        // D-01: main domain bypasses the guard entirely.
        if (isMainDomain()) {
            setReady(true)
            return
        }
```

Change it to:
```typescript
        // D-01: main domain bypasses the guard entirely.
        // Unauthenticated users skip the domain lookup — ProtectedRoute redirects them immediately.
        if (isMainDomain() || !isAuthenticated()) {
            setReady(true)
            return
        }
```

**Why this is correct:** `PrimaryDomainRedirect` only matters for authenticated users who might be visiting a non-primary domain and need to be silently moved to the primary. Unauthenticated users are heading to `/auth/login` regardless — the domain lookup would only delay their redirect with a blank-screen wait. Skipping it is safe: they never reach `Outlet` — `ProtectedRoute` intercepts them first.

No other lines in the file change. The D-02 blank-screen behavior (rendering `null` while loading) is preserved for authenticated users.
