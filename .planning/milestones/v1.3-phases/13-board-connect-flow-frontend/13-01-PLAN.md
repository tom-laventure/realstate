<objective>
Implement the test-board bypass flow in ConnectBoardDialog: when an admin selects a board where `isTestBoard` is true, clicking Next skips the credentials step and instead shows an informational notice step. The Connect button on that step submits the credential payload without username or password.

Purpose: Test board users should never be confronted with a RETS credentials form — it is meaningless for sample-data boards. The backend (Phase 12, BOARD-04) already accepts credential-free payloads for test boards; this phase wires the matching frontend behavior.

- `boardType.ts` — `isTestBoard: boolean` on `RealEstateBoardType`; `retsUsername?` / `retsPassword?` made optional on `CreateBoardCredentialPayload`
- `ConnectBoardDialog.tsx` — new `'test-board-info'` step union member, routing logic, JSX for the info step, updated `handleSubmit` guard
