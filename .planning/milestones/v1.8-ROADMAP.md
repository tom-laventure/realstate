## Milestone Summary

**Key Decisions:**

- ROUTE-01 fix targets `SubdomainOnly` (DomainGuard.tsx), not an index route in `MainDomainOnly` — the `dashboard` route at `path: '/'` in Block 1 always wins over Block 2 due to React Router array-order tiebreaker; any index route in `MainDomainOnly` would be unreachable dead code
- `isAuthenticated()` early-return guard added alongside `isMainDomain()` in `PrimaryDomainRedirect` — skips `lookupDomain()` API call for unauthenticated users entirely

**Issues Resolved:**

- Main domain `/` showed NotFound (blank) for unauthenticated users — now redirects to `/dashboard` → `/auth/login` (ROUTE-01)
- Brokerage subdomain `/` showed a blank-screen flash during `lookupDomain()` API call for unauthenticated users — now skips lookup immediately (ROUTE-02)
- Initial PLAN.md approach (index route inside `MainDomainOnly`) was dead code — code review caught this before execution
