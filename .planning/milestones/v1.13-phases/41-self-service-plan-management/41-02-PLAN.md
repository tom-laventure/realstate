<objective>
Build the frontend data layer for self-service plan management: a new owner-only `manage_plan` RBAC permission, a shared `PlanTier` type, the Axios call + TanStack mutation to `PATCH /v1/admin/settings/plan`, and the extension of the existing settings Brain (`useSettingsAdminContext`) with plan state and a branching `handlePlanChange` action (downgrade → open dialog; upgrade/lateral → mutate immediately).

Purpose: PLAN-22 (read current plan via the already-fetched `brokerage.plan` — no new GET endpoint), PLAN-23 (owner-only edit gate via `manage_plan`), and PLAN-24 (client call to the real endpoint from Plan 01). Success handling (optimistic tier + toast + single-key invalidation) lives in ONE mutation so both the direct and dialog-confirm call sites in Plan 03 share it (RESEARCH.md Pitfall 4).
Output: One modified config file, one modified Brain, and three new files (type, api, hook).
