currently allow owner-role changes without an owner-only + last-owner guard:
`UsersController#update` (D-02), `UsersController#destroy` (D-01), and
`InvitationsController#create` (D-03 / LOCK-01). This is the backend half of the
add-agent lockdown and the users-endpoint hardening.

enforcement until these bypass paths are closed. All owner-role changes must be forced
through the new `/admin/settings/owners` endpoints (Plan 02), which alone carry the
last-owner guard.
Output: Two edited controllers + one new integration test file proving every bypass
path returns the correct rejection.
</objective>
