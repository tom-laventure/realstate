## Milestone Summary

**Decimal Phases:** None — all phases were planned in sequence.

**Key Decisions:**

- Phase 8: `decimal(10,6)` for lat/lng — preserves ~0.1m precision; no float rounding loss
- Phase 8: `geocoding_failed boolean default false not null` — PostgreSQL ≥11 metadata-only migration; existing rows auto-backfilled
- Phase 8: WebMock for HTTP stubbing (minitest 6.x has no `Object#stub`); `run_after_discard_procs(nil)` for after_discard testing (Rails 7.1 API)
- Phase 9: react-map-gl/mapbox entry point (`not react-map-gl`) — required for Mapbox GL JS v3 bundle compatibility
- Phase 9: `Map` renamed to `MapGL` at import — avoids shadowing JS global `Map` constructor in `useMemo(() => new Map(...))`
- Phase 9: `fitBounds` guarded by `hasFitBoundsRef` — prevents jarring re-center on filter change; fits only on initial load
- Phase 9: `coordById` lookup via `new Map(coordinates.map(...))` for O(1) cluster leaf resolution
- Phase 9: Hero image falls back to `images[0]` when `hero_image_url` is null — seed data gap
- Phase 10: `!= null` loose equality guard accepts `0.0` as valid coordinate while rejecting null/undefined
- Phase 10: Map placed outside tab system — no re-mount on tab switch (Pitfall 4 from RESEARCH.md)

**Issues Resolved:**

- Pin click not firing popup — childless Mapbox `<Marker>` doesn't reliably deliver click events through react-map-gl v8; fixed by providing custom `<button>` child with `stopPropagation()`
- Hero image null in coordinates endpoint — `hero_image_url` was nil for seed data; fixed by coalescing with `images.first` in backend SELECT
- Google Maps → Mapbox migration — Plan 03 originally installed Google Maps libs; revised to Mapbox before execution based on project standard established in Phase 9 CONTEXT.md

**Issues Deferred:**

- RETS/MLS coordinate ingestion — D-06; geocoding-from-address is the active path; MLS feeds vary by board
- Spatial index (PostGIS) — deferred; current Nominatim-based scale doesn't require it
- Mapbox bundle size (~1.78MB raw / 492KB gzip) — code splitting deferred to future optimization phase

**Technical Debt Incurred:**

- `routes.rb` has pre-existing `ExtraSpacing` standardrb violations in the calendar namespace block (lines 41-48) — pre-existing, out of scope
- `tsc --noEmit` incompatibility with TypeScript 4.9.5 / `moduleResolution: bundler` — pre-existing; `npm run build` is the authoritative type check
