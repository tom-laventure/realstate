<objective>
Replace the monolithic AppShellAdmin shell on the main domain with PortalAdminShell — a clean portal-native wrapper that renders PortalNavBar (brokerage switcher) and an Outlet, with no subdomain Navbar, SideNav, or Footer. Subdomain behavior is unchanged.

The core problem: navigating to /admin/brokerage on the main domain currently renders AppShellAdmin which shows the subdomain Navbar (with Groups Overview and other user-facing links) and SideNav. The portal nav (PortalNavBar with brokerage switcher) disappears once you leave PortalShell. This contradicts the milestone goal of a coherent main-domain admin experience.

The fix is a domain-adaptive shell: one AdminDomainShell component at the admin route root that delegates to PortalAdminShell on the main domain and AppShellAdmin on subdomains. One route definition — no React Router path conflicts.

Output: Three files. PortalAdminShell.tsx (new shell). AdminDomainShell.tsx (domain switch). admin.tsx updated to use AdminDomainShell as element.
</objective>

```tsx
import { isMainDomain } from '@/helpers/domain'
import AppShellAdmin from '@/components/common/shells/appShellAdmin/AppShellAdmin'
import PortalAdminShell from '@/components/common/shells/portalAdminShell/PortalAdminShell'

// Renders PortalAdminShell on the main domain (brokerage switcher nav, no subdomain chrome)
// and AppShellAdmin on subdomains (existing nav + sidenav). One route definition — no
// React Router path conflict from registering /admin/ under two domain-guarded blocks.
const AdminDomainShell = () => {
    return isMainDomain() ? <PortalAdminShell /> : <AppShellAdmin />
}

export default AdminDomainShell
```

Constraints:
- This component calls no hooks itself — it only delegates to one of two shell components. The hooks inside AppShellAdmin and PortalAdminShell only run when their respective component renders.
- Do NOT call isMainDomain() inside a useEffect or useMemo — it reads window.location.hostname which is stable for the lifetime of the page; direct call in render is correct.
