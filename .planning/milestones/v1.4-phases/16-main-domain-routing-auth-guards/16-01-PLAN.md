Create the imperative wrapper hook that satisfies CLAUDE.md's "Never call axios or API functions directly inside a component — always go through a hook" rule for the LoginSuccessful main-domain branch.

**Why a thin imperative wrapper (not `useQuery`):**
`LoginSuccessful` is a fire-once lifecycle component — it reads the post-Cognito hash token, fetches admin brokerages once, then navigates (component unmounts). It is NOT a persistent data-fetching context. A `useQuery` hook would be orphaned by the immediate unmount-after-navigate. The hook therefore returns the API function directly so the component can `await` it inside its existing `useEffect`. This technically satisfies CLAUDE.md ("through a hook") while preserving the fire-once lifecycle semantics required by RESEARCH.md Pattern 4 and the Project Constraints note.

```typescript
                        Please sign in directly at your brokerage URL.
                    </div>
                </div>
                <Button className="w-full" onClick={handleSignOut} disabled={signingOut}>
                    Sign Out
                </Button>
            </div>
        </div>
    )
}

export default NoAccess
```

| Boundary | Description |
|----------|-------------|
| Browser ↔ React Router | Client-side routing decisions for `/dashboard/*` and `/no-access`. UX enforcement only; not a security boundary. |
| Component ↔ localStorage | `isAuthenticated()` reads token from localStorage; `clearToken()` removes it. Trusted because Cognito-issued JWT is verified server-side on every API call. |
| Browser ↔ Amplify | `signOut({ global: true })` invalidates the Cognito session globally. Network failures swallowed by `.catch(() => null)` — local cleanup must still execute. |
