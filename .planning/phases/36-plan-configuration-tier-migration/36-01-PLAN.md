<objective>
Create the single, centralized, code-level plan-tier config (`AppConstants::PLAN_TIERS`) that defines seat caps, base prices, per-seat overage rates, the annual discount, and capability flags for `free`/`independent`/`growth`, plus a reusable `Brokerage#plan_config` accessor. This is the foundation every gating and billing rule in Phases 37-39 reads from.

Purpose: Eliminate scattered `plan == "premium"` string comparisons (PLAN-02) by giving the whole app one config-driven integration point (D-07). Encode the locked pricing (PLAN-10, PLAN-11) and the 15%-annual-discount-on-base-only rule (PLAN-13/D-04) so that raising or lowering any tier value is a one-file change (PLAN-03).

Output: `app/constants/plan_tiers.rb` (new), `Brokerage#plan_config` accessor added to `app/models/brokerage.rb`, and a focused test proving the values and accessor.

Scope boundary: This plan does NOT flip the model's `plan` inclusion validation and does NOT run the data migration or rewire any controller — those all land in plan 36-02 as one atomic unit. After this plan, the full test suite stays green (the accessor is added but not yet consumed anywhere).
</objective>
