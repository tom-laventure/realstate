## Dialog State Machine

### Type Declaration

```ts
type ConnectBoardStep = 'select' | 'test-board-info' | 'credentials' | 'success'
```

`'test-board-info'` is the new step added in this phase. The `'credentials'` step is never shown for test boards.

### Flow

**Test board selected (`selectedBoard.isTestBoard === true`):**

```
select → test-board-info → success
```

**Real board selected (`selectedBoard.isTestBoard === false`):**

```
select → credentials → success
```

### Step Routing Logic (in `select` step's Next button `onClick`)

```ts
onClick={() => {
  if (selectedBoard?.isTestBoard) {
    setStep('test-board-info')
  } else {
    setStep('credentials')
  }
}}
```

### Reset Logic (`handleOpenChange`)

When dialog closes (`nextOpen === false`), reset `step` to `'select'`. The new `'test-board-info'` step requires no additional state to reset — it holds no local inputs.

## New Step: `test-board-info`

### Layout

Follows the same `DialogHeader` + `div.space-y-4.pt-2` shell used in all other steps.

### Dialog Header

- `DialogTitle`: "Connect a Realtor Board" — identical to the `select` step title. No title change on step transition.
- `DialogDescription`: "Review the information below before connecting." — replaces the generic description for this step.

### Info Notice

```tsx
<div className="rounded-md border border-blue-200 bg-blue-50 px-4 py-2 text-xs text-blue-800 flex items-start gap-2">
  <Info className="h-4 w-4 mt-0.5 shrink-0" />
  <span>
    This board contains sample listings for development — no real credentials required.
  </span>
</div>
```

- Icon: `Info` from `lucide-react`, size `h-4 w-4`, `mt-0.5` for baseline alignment, `shrink-0`
- Notice text: exactly "This board contains sample listings for development — no real credentials required."
- Structure: `flex items-start gap-2` — icon left-anchored to first line of text
- Classes match yellow notice dimensions exactly (`rounded-md`, `px-4 py-2`, `text-xs`) for visual consistency

### Action Row

```tsx
<div className="flex items-center justify-between pt-1">
  <button
    type="button"
    onClick={() => setStep('select')}
    className="flex items-center gap-1 text-sm text-muted-foreground hover:text-foreground transition-colors"
  >
    <ChevronLeft className="h-4 w-4" />
    Back
  </button>
  <Button
    onClick={handleSubmit}
    disabled={isSubmitting}
  >
    {isSubmitting && <Loader2 className="mr-2 h-4 w-4 animate-spin" />}
    Connect
  </Button>
</div>
```

- Back button: identical pattern to credentials step back button — `text-sm text-muted-foreground hover:text-foreground transition-colors`, `ChevronLeft` icon
- Back navigates to `'select'` step
- Connect button: primary `Button` variant, labeled "Connect", same as credentials step CTA
- Loading state: `Loader2` spinner with `animate-spin` shown when `isSubmitting === true`

### `handleSubmit` for Test Boards

The existing guard `if (!selectedBoardId || !username || !password) return` must be updated:

```ts
const handleSubmit = async () => {
  if (!selectedBoardId) return
  const isTestBoard = selectedBoard?.isTestBoard ?? false
  if (!isTestBoard && (!username || !password)) return
  // ... rest unchanged
}
```

Payload for test board submit: `{ realEstateBoardId: selectedBoardId }` — no `retsUsername`/`retsPassword` keys (or both omitted since they are now optional).
