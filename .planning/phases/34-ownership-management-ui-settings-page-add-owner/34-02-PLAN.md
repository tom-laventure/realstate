## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Viewer role → rendered UI | `<Can permission="manage_ownership">` decides whether owner-only action UI (Add Owner button, dialog) renders vs the read-only RolePermissions card |
| Selected user_id → promote mutation | The dialog passes a client-selected `user_id` to the server-enforced promote endpoint |
| RolePermissions roles prop | Passing the default (client-inclusive) prop would disclose a role card for a role that can never reach this page |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
