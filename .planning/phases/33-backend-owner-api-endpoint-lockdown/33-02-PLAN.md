<objective>
Ship the four new owner-management endpoints under a new
`V1::Admin::Settings::OwnersController`: list owners (API-01), list eligible
promotable users (API-02), promote (API-03), and demote with a last-owner guard
(API-04) — all enforcing caller role server-side via the DB-backed `current_membership`
helper (API-05).

Purpose: This is the owner-only API surface that Phase 34/35's Ownership Management UI
consumes. It is the ONLY path that may assign or remove the owner role (the generic
endpoints are locked down in Plan 01), and the only place carrying the last-owner
invariant for demotion.
Output: One new controller, a new route block, and a new integration test file.
</objective>
