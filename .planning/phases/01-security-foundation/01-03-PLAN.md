```ruby
Rails.application.config.middleware.insert_before 0, Rack::Cors do
  allow do
    origins do |source, _env|
      host = begin
        URI.parse(source).host&.downcase
      rescue URI::InvalidURIError
        nil
      end
      host.present? && BrokerageDomain.exists?(domain: host)
    end

    resource "*",
      headers: :any,
      methods: %i[get post put patch delete options head],
      expose: %i[Authorization access-token expired token-type uid client]
  end
end
```

Critical: The column name is `domain` (NOT `host`) — confirmed from schema.rb. Using `host:` would silently return false. See Pitfall 5 in RESEARCH.md.

The URI.parse rescue handles malformed Origin headers gracefully — returns nil, proc returns false, CORS rejected.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser Origin → Rack::CORS | Every cross-origin preflight and request now requires the Origin host to exist in BrokerageDomain table |
| HTTP client → POST /v1/sessions | Rate limiter counts per-IP using SolidCache (PostgreSQL) — shared across all Puma workers |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Spoofing | CORS origins wildcard | mitigate | Dynamic proc validates Origin host against BrokerageDomain.exists?(domain:) — arbitrary origins rejected |
| T-03-02 | Denial of Service (login brute force) | POST /v1/sessions | mitigate | rack-attack throttle: 5 req/20s per IP; exceeding returns 429 JSON; counters shared via SolidCache/PostgreSQL across Puma workers |
| T-03-03 | Denial of Service (CORS DB query) | BrokerageDomain.exists? in CORS proc | accept | Query uses unique index on domain column — fast; acceptable at current scale; no caching needed yet |
| T-03-04 | Elevation of Privilege | req.env["REMOTE_ADDR"] vs req.ip | mitigate | Throttle key uses req.ip (reads X-Forwarded-For) per D-15 — behind Nginx/LB, REMOTE_ADDR is the proxy IP |
| T-03-05 | Information Disclosure | Dev domain seeds in production | accept | Seeds are idempotent via unique_by; localhost resolves to loopback and would never receive external requests; gregoryrealtor.realstate.local is a non-routable .local domain |
</threat_model>
