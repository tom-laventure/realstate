<objective>
Wire the account Calendar tab to the cross-brokerage `calendar_sync_available` boolean the backend exposes (Plan 02), rendering `FreeTierBanner` in place of the provider-card grid for fully-Free users while keeping the tab visible (D-08). This is the one gated surface that does NOT use `hasPlanCapability` — calendar access is user-scoped and cross-brokerage, so the authoritative signal is the backend boolean, not the current brokerage's plan.

Purpose: `UserCalendarConnection` is user-scoped; a user with any paid membership keeps calendar sync even while viewing a Free brokerage (D-06). Deriving this from `brokerage.plan` would be wrong. The backend already computed it (Plan 02) — thread it through.
Output: Response type + hook + context + tab wiring.
</objective>
