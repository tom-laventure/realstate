Modify `backend/app/models/brokerage.rb`. Add two public instance methods after the existing `phasing_out_count_for` method:

```ruby
# DPRD-01, DPRD-03: Plan downgrade — freeze all custom domains and promote subdomain to primary.
# Called by Ops::PlanController (manual testing) and future billing webhook (v2).
# IMPORTANT: Does NOT send email. The caller (Ops::PlanController) dispatches
# DomainMailer.downgrade_notice after this method returns, so that:
#   1. The model method is testable without a mailer dependency.
#   2. The email is sent only after the DB transaction has committed.
def freeze_custom_domains!
  ApplicationRecord.transaction do
    # DPRD-01: freeze active, pending, and phasing_out custom domains
    brokerage_domains.domain_type_custom
                     .where(status: %w[active pending phasing_out])
                     .update_all(status: "frozen")
    # DPRD-03: clear all primary flags, then set subdomain as primary
    brokerage_domains.update_all(is_primary: false)
    brokerage_domains.domain_type_subdomain
                     .status_active
                     .first
                     &.update!(is_primary: true)
  end
end

# DPRD-06: Plan re-upgrade — selectively restore frozen custom domains.
# Frozen domains that were previously active (verified: true)  → restored to "active".
# Frozen domains that were previously pending (verified: false) → restored to "pending".
# Does NOT restore is_primary to frozen domains — owner must manually reassign primary.
def unfreeze_custom_domains!
  # Previously-active custom domains (verified) go back to active
  brokerage_domains.domain_type_custom
                   .status_frozen
                   .where(verified: true)
                   .update_all(status: "active")
  # Previously-pending custom domains (unverified) go back to pending
  brokerage_domains.domain_type_custom
                   .status_frozen
                   .where(verified: false)
                   .update_all(status: "pending")
end
```

IMPORTANT notes:
- `freeze_custom_domains!` MUST NOT call `DomainMailer.downgrade_notice` — the caller handles email dispatch. This avoids a Wave 2 dependency on Plan 22-02 (DomainMailer).
- `update_all` is safe for the bulk status transitions here because:
  - `frozen` does not trigger `status_requires_verified` (only `status_active?` triggers it)
  - For unfreeze (frozen → active), previously-active domains already have `verified: true`, satisfying the `status_requires_verified` invariant. `update_all` bypasses validations, but the data invariant holds because we scope to `verified: true`.
  - For unfreeze (frozen → pending), previously-pending domains have `verified: false`, which is valid for `pending` status.
- Do NOT wrap `unfreeze_custom_domains!` in a transaction — it is two independent `update_all` statements (each atomic by itself) and there is no multi-step dependency requiring a single atomic boundary.

```ruby
module Ops
  # D-06: JSON endpoint for manual freeze/unfreeze of brokerage custom domains.
  # Used for testing before billing webhook integration (v2).
  # Returns JSON — must skip CSRF (inherited from BaseController which has protect_from_forgery).
  # Email dispatch (DPRD-05) happens here, after the model transaction commits, to keep
  # Brokerage#freeze_custom_domains! free of mailer dependencies.
  class PlanController < BaseController
    skip_before_action :verify_authenticity_token, raise: false
    before_action :set_brokerage

    # POST /ops/brokerages/:brokerage_id/plan
    # Params: { freeze: true|false }
    def update
      freeze = ActiveModel::Type::Boolean.new.cast(params[:freeze])
      if freeze
        @brokerage.freeze_custom_domains!
        # DPRD-05: email owners after transaction commits — dispatched by controller, not model
        DomainMailer.downgrade_notice(@brokerage).deliver_now!
        render json: {status: "frozen", brokerage_id: @brokerage.id}, status: :ok
      else
        @brokerage.unfreeze_custom_domains!
        render json: {status: "unfrozen", brokerage_id: @brokerage.id}, status: :ok
      end
    rescue ActiveRecord::RecordInvalid => e
      render json: {error: e.message, details: e.record.errors.full_messages}, status: :unprocessable_entity
    rescue => e
      render json: {error: e.message}, status: :unprocessable_entity
    end

    alias_method :create, :update

    private

    def set_brokerage
      @brokerage = Brokerage.without_deleted.find(params[:brokerage_id])
    rescue ActiveRecord::RecordNotFound
      render json: {error: "Brokerage not found"}, status: :not_found
    end
  end
end
```
