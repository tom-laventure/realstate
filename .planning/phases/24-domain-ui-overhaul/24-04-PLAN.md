| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-24-11 | Elevation of Privilege | delete-primary issues set_primary + destroy; could a non-owner trigger it via devtools | mitigate | Both `set_primary` and `destroy` remain behind `require_owner!` (Plan 01 unchanged); client `Can` gating is UX-only and not the authorization boundary |

| T-24-13 | Information Disclosure | replacement dropdown lists domains | mitigate | Dropdown is populated only from `state.domains`, which is the current brokerage's tenant-scoped list (backend index scoping, Plan 01) |
</threat_model>
