```ruby
# POST /v1/admin/domains/:id/verify
# DVER-01: on-demand DNS check. Accessible to admin + owner (default require_admin!).
def verify
  domain = Current.brokerage.brokerage_domains.find_by(id: params[:id])
  return render json: {error: "Domain not found"}, status: :not_found unless domain

  unless %w[pending phasing_out].include?(domain.status)
    return render json: {error: "Domain is not in a verifiable state"}, status: :unprocessable_entity
  end

  base_domain = ENV.fetch("APP_BASE_DOMAIN", "realstate.ca")
  server_ip = ENV.fetch("APP_SERVER_IP", nil)

  if dns_resolves?(domain.domain, base_domain, server_ip)
    ApplicationRecord.transaction do
      locked = BrokerageDomain.lock.find(domain.id)
      if locked.status_phasing_out?
        locked.update!(status: :active, consecutive_failures: 0, last_checked_at: Time.current, phase_out_at: nil)
      elsif locked.status_pending?
        locked.update!(status: :active, verified: true, verified_at: Time.current, consecutive_failures: 0, last_checked_at: Time.current)
        if locked.set_primary_on_verify? || locked.brokerage.brokerage_domains.where(is_primary: true).none?
          locked.brokerage.brokerage_domains.update_all(is_primary: false)
          locked.update!(is_primary: true, set_primary_on_verify: false)
        end
      end
    end
    render json: mutation_payload(domain.reload, :custom), status: :ok
  else
    domain.update_column(:last_checked_at, Time.current)
    render json: {
      verified: false,
      error: "CNAME record not detected",
      domain: ActiveModelSerializers::SerializableResource.new(
        domain.reload, serializer: BrokerageDomainSerializer, adapter: :attributes
      ).as_json
    }, status: :ok
  end
end
```

Add the `dns_resolves?` private method copied verbatim from `v1/onboarding/domains_controller.rb` (lines 62-83) into the `private` section of this controller. Add `require "resolv"` at the top of the file if not already present.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client → POST /v1/admin/domains/:id/verify | Authenticated admin/owner triggers a DNS lookup against a brokerage-owned domain |
| verify action → external DNS resolver | Server performs an outbound DNS query for the domain name |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-24-01 | Information Disclosure | verify action reading another brokerage's domain | mitigate | `Current.brokerage.brokerage_domains.find_by(id: params[:id])` scopes the lookup to the tenant; cross-tenant id returns 404 (test 1/4 cover owner-scope) |
| T-24-02 | Elevation of Privilege | verify reachable by non-admin roles | mitigate | `verify` omitted from `require_owner!` but still behind default `require_admin!` (owner+admin); agent-role test asserts 403 |
| T-24-03 | Tampering / SSRF | DNS lookup target controlled by attacker | accept | `dns_resolves?` queries only `domain.domain`, which must already be a brokerage-owned record created via the validated custom flow; no arbitrary host is resolvable. Resolv::DNS issues a standard recursive query, not an HTTP request — no SSRF surface |
| T-24-04 | Denial of Service | repeated verify calls flooding DNS resolver | accept | Synchronous resolver call is bounded by Resolv timeout; owner/admin-only and per-domain. Rate limiting deferred — low-value internal admin endpoint |
</threat_model>
