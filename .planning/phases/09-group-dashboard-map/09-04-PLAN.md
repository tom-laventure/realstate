- cooperativeGestures prop on Map
- Four shell states: no token / loading / error / empty

GeneralDashboard: already wired — GroupMapPanel import and JSX insertion present.

Key implementation notes:
- CSS import ('mapbox-gl/dist/mapbox-gl.css') must be present or map tiles won't render
- cooperativeGestures prevents scroll hijacking (equivalent to gestureHandling="cooperative")
- Cluster size: Math.round(28 + (point_count / coordinates.length) * 20)px — scales between 28–48px
- Bounds must be updated on both onLoad and onMove to keep clustering accurate after pan/zoom
- supercluster.getLeaves(clusterId, Infinity) — Infinity returns all leaves (no pagination)
