| Token | Value | Usage |
|-------|-------|-------|

| 2xl | 48px | — |
| 3xl | 64px | — |

Exceptions:
- Nav item icon container: `h-8 w-8` (32px square) with `flex items-center justify-center` — matches existing `AdminBoardSideNav` icon wrapper pattern

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `--background: oklch(1 0 0)` (white) | Page background, card backgrounds |
| Secondary (30%) | `--sidebar: oklch(0.985 0 0)` (near-white) | Sidebar background, nav container |

| Destructive | `--destructive: oklch(0.577 0.245 27.325)` (red) | Delete connection action, Invalid badge |

Accent reserved for:
- Active nav item background (`bg-sidebar-accent text-sidebar-accent-foreground`)
- Nav item hover state (`hover:bg-sidebar-accent hover:text-sidebar-accent-foreground`)
- Icon wrapper background in `AdminBoardSideNav` (`bg-sidebar-accent/40`)

NOT used for: CTAs (those use `--primary`), form inputs, general interactive elements.

Additional semantic colors in use (inherited, not new):
- `bg-green-100 text-green-800` — Active board status badge
- `--muted-foreground` — Secondary text (region, dates, empty state, column headers)
- `--primary` — "Connect Board" button fill

## Interaction Contract

### Nav item active state

Both sidebars use `startsWith` matching. The new "Board Registrations" item at `/admin/boards` will:
- Be active when `location.pathname` starts with `/admin/boards`
- Be inactive when at `/admin/brokerage` (no prefix overlap)
- Visually: `bg-sidebar-accent text-sidebar-accent-foreground` when active; `text-sidebar-foreground hover:bg-sidebar-accent hover:text-sidebar-accent-foreground` when inactive

### BoardRegistrations actions (unchanged)

| Action | Trigger | Interaction |
|--------|---------|-------------|
| Connect Board | Click "Connect Board" button | Opens `ConnectBoardDialog` modal |
| Edit credentials | Click row action menu → "Edit credentials" | Opens `EditBoardCredentialDialog` modal |
| Delete connection | Click row action menu → "Delete connection" | Opens `AlertDialog` confirmation |
| Confirm delete | Click "Delete" in AlertDialog | Fires `onDeleteCredential`, closes dialog |
| Cancel delete | Click "Cancel" or dismiss | Closes dialog, no mutation |

All interactions above are implemented in the existing `BoardRegistrations` component. The new `BoardsAdminBoard` container passes the same prop signatures as the current `BrokerageAdminBoard`. No interaction change.

### Focus and accessibility

- Nav items: `aria-current="page"` on active item — existing pattern, must be preserved in both sidebars
- All dialog components use Radix UI primitives (via shadcn) which manage focus trap, escape key dismissal, and `aria-modal` automatically
- Row action `DropdownMenuTrigger` carries `aria-label={Row actions for {board name}}` — existing, must be preserved
