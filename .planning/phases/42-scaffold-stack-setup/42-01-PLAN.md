<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| npm registry → developer machine / Vercel build container | Untrusted third-party code enters the build via `npm create astro@latest`, `astro add tailwind`, and the transitive dependency tree. This is the only meaningful trust boundary in this plan — `landing/` has no server, no auth, no user input, and no coupling to `backend/` or `frontend/`. |
| Monorepo git tree → deployed artifact | Whatever is tracked under `landing/` becomes publicly served static content once Phase 45 wires the Vercel project. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-42-SC | Tampering | `npm create astro@latest`, `astro add tailwind`, transitive npm tree | mitigate | Task 1 is a blocking-human package legitimacy checkpoint (no `## Package Legitimacy Audit` table exists in milestone research, so all packages are treated as `[ASSUMED]`); `package-lock.json` is committed so the resolved tree is reproducible and reviewable in future diffs |
| T-42-01 | Tampering | `@astrojs/tailwind` (deprecated) vs `@tailwindcss/vite` | mitigate | Task 3 acceptance criteria assert `@astrojs/tailwind` is absent from `landing/package.json`; installing an unmaintained integration would widen the dependency surface with no security-patch cadence |
| T-42-02 | Tampering | `landing/.git` nested repository | mitigate | `--no-git` flag plus a `test ! -e landing/.git` assertion in Task 2; a nested repo silently converts `landing/` into an embedded repository, breaking DEPLOY-01 and deploying an empty tree |
| T-42-03 | Denial of Service | Astro build under Node 22.9.0 (below the >=22.12.0 engine floor) | mitigate | Task 2 hard-gates on `node -v >= 22.12.0` before any Astro command and pins `engines.node` in `package.json` so Vercel selects a compatible runtime |
| T-42-04 | Spoofing / Repudiation / Elevation of Privilege | n/a | accept | `landing/` is a static site with no authentication, no session, no user input, no server-side execution, and no data store — these STRIDE categories have no applicable component in this phase |
| T-42-05 | Information Disclosure | Secrets accidentally committed under `landing/` | accept (this plan) | No env vars or secrets are introduced in Phase 42; Plan 02 asserts `landing/.gitignore` covers `.env*` before any content work begins |
</threat_model>
