<production_not_preview_gotcha>
The first deployment created by this runbook builds from `master` with **`VERCEL_ENV=production`**, not `preview`, even though its only reachable URL is the `*.vercel.app` alias and no custom domain exists yet. Consequences for Task 3:

- The served home page will correctly **not** carry `name="robots" content="noindex"`. That is expected, not a bug — do not fail verification on it.
- `/privacy` and `/terms` **will** carry `noindex` in every environment (Phase 43 D-09 makes them always-noindex).
- Critically: absence of `noindex` on the home page is **also** what a build with `VERCEL_ENV` entirely unavailable would produce. The live fetch therefore **cannot** discriminate "System Environment Variables enabled" from "System Environment Variables missing". Do not claim it does. That setting is confirmed in the dashboard in plan 45-02.
</production_not_preview_gotcha>
