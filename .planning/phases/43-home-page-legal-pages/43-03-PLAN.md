| Boundary | Description |
|----------|-------------|
| Public internet → `/privacy`, `/terms` static HTML | Placeholder legal content served without auth to anyone, including prospective customers and search crawlers |
| Search-engine crawler → legal page markup | Crawlers may index and cache non-final legal text if not explicitly excluded |
| `landing/` origin → `app.realtybase.ca` (via shared SiteHeader/SiteFooter) | Same cross-origin CTA surface as the home page |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-43-10 | Repudiation | Placeholder legal text on `/privacy` and `/terms` | mitigate | A visitor or customer could later claim the placeholder text constituted binding terms. Mitigated by the `LegalNotice` banner, which UI-SPEC places directly between the `<h1>` and the first `<h2>` using the reserved `--destructive` treatment; both tasks assert its byte position in the built HTML so it cannot silently drift below body content (Pitfall 3 / Pitfall 6). |

| T-43-12 | Information Disclosure | Over-claiming in placeholder privacy copy | mitigate | Sections 3, 6, 7, 9, and 11 are constrained to generic language: no compliance assertions for GDPR/CCPA/PIPEDA/Law 25, no enumeration of specific analytics fields, no claimed retention windows. Asserting a control the product does not yet implement would itself be a misrepresentation. |
| T-43-13 | Tampering | Pricing facts duplicated in ToS section 5 | mitigate | ToS section 5 is asserted to contain no currency-plus-digit, per-seat, per-month, or tier-name string.
