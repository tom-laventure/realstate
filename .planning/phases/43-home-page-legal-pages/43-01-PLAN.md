## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| npm registry → `landing/node_modules` | Third-party package code executes at build time on the developer machine and in CI |
| `landing/` origin → `app.realtybase.ca` origin | Outbound cross-origin navigation from CTA links; two different Vercel projects, no shared state |
| Public internet → static HTML | Every byte served is public; there is no auth, session, form input, or backend call on this site |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-43-SC | Tampering | `npm install @lucide/astro` (Task 1) | mitigate | Package audited in `43-RESEARCH.md` Package Legitimacy Audit: slopcheck `[OK]`, official `github.com/lucide-icons/lucide` repo, no postinstall script, disposition **Approved** — no `[ASSUMED]`/`[SUS]`/`[SLOP]` packages in this phase, so no legitimacy checkpoint is required. Task 1 asserts the scoped name `@lucide/astro` and asserts absence of the deprecated unscoped `lucide-astro`, which is the concrete typosquat/legacy-package risk here. `package-lock.json` is committed to pin the resolved tree. |
| T-43-01 | Spoofing | CTA link destinations in `consts.ts` (Task 2) | mitigate | Both destinations are hardcoded absolute `https://` URLs to a known first-party origin, defined once in `consts.ts` and never derived from user input, query params, or env vars — there is no injection surface. Task 3 asserts no component inlines a URL, so the single definition cannot be bypassed. |
| T-43-02 | Information Disclosure | `SiteHeader`/`SiteFooter` outbound links (Task 3) | mitigate | All links are same-tab; Task 3 asserts no `target="_blank"` exists. Reverse-tabnabbing therefore has no attack surface. If a future phase adds a new-tab link, it must ship `rel="noopener noreferrer"` unconditionally. |
| T-43-03 | Tampering | Client-side script execution on `landing/` | mitigate | Zero client JS by design (D-03). No `client:*` directive, no `<script>` tag, no framework island is introduced. `SiteFooter`'s year is computed in Astro frontmatter (Node, build time), asserted by the `getFullYear` + no-`<script>` acceptance criteria. |
| T-43-04 | Information Disclosure | `landing/` static asset surface | accept | The site serves only public marketing content — no secrets, no PII, no env values, no API keys are referenced. `consts.ts` holds only public URLs and a public support email. Low-value target with nothing confidential to disclose. |
