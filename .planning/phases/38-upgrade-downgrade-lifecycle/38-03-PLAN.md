## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Ops-triggered job → bulk state mutation | The job freezes/suspends/purges/restores en masse; a wrong-direction classification or over-broad restore could revoke or reactivate access incorrectly |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-38-05 | Elevation of Privilege | Re-upgrade restore query | mitigate | Restore is scoped to `suspended_at == plan_downgraded_at`; a credential/membership suspended by an earlier or unrelated event is never reactivated (Task 2 negative test asserts this) |
| T-38-06 | Tampering | Direction classification (`paid?`) | mitigate | Direction derived from `old_plan`/`new_plan` string values against the validated `%w[free independent growth]` set; paid→paid and free→free are explicit no-ops so no cascade fires on a misdirected transition |
| T-38-02 | Repudiation (irreversible loss) | Upgrade purge dispatch | mitigate | Purge is delegated to the double-scoped `TestBoardPurgeService` (Plan 02); job adds no additional destructive query |
| T-38-07 | Denial of Service | Synchronous cascade blocking Ops request | mitigate | All cascades run inside this ActiveJob (D-02), never inline in the controller; `retry_on` bounds failure retries at 3 |
| T-38-SC | Tampering | Package installs | accept | No new packages — solid_queue/ActiveJob already present |
