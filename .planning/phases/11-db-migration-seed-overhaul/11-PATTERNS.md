**New `seed_real_estate_boards!` pattern:**
```ruby
def seed_real_estate_boards!
  puts "Seeding RealEstateBoards..."

  # Remove old boards before upserting TEST — upsert_all alone only INSERT/UPDATES
  # by unique_by key; REBGV/FVREB/CADREB rows would remain without this delete.
  # RealEstateBoard has no acts_as_paranoid — delete_all (no callbacks) is correct.
  RealEstateBoard.where.not(short_code: "TEST").delete_all

  now = Time.current
  boards = [
    {
      name: "Test RETS Board",
      short_code: "TEST",
      rets_endpoint: "https://test.example.com/rets/login",
      region: "North Vancouver",
      is_test_board: true,
      active: true,
      created_at: now,
      updated_at: now
    }
  ]

  RealEstateBoard.upsert_all(boards, unique_by: :short_code)
  puts "  RealEstateBoards: #{RealEstateBoard.count}"
end
```

**`seed_board_credentials!` function to DELETE entirely** (lines 39-81):
- Remove the entire function definition; it will no longer be called from seeds.rb

**Critical pitfall:** `rets_endpoint` has `validates :rets_endpoint, presence: true` on the model AND `null: false` in the schema. `upsert_all` bypasses AR callbacks but NOT DB constraints. The TEST board MUST include a non-null `rets_endpoint` value.
