<objective>
Create a Rails Rack middleware that intercepts every HTTP request and issues a 301 redirect from non-primary domains (active, phasing-out, and frozen) to the same path on the brokerage's current primary domain. Register it early in the middleware stack so it runs before any controller logic (BrokerageAuth). This closes DPRI-04 (non-primary 301 redirect) and DPRD-02 (frozen domains serve only a redirect to the subdomain).

Purpose: Non-primary domains must transparently redirect to the canonical primary domain at the server layer (SEO-correct permanent redirect, no full app load on non-primary or frozen domains).
Output: `app/middleware/domain_redirect_middleware.rb`, its registration in `config/application.rb`, and a full middleware test file.
</objective>

Create `backend/app/middleware/domain_redirect_middleware.rb` defining `class DomainRedirectMiddleware` following the standard Rack protocol (`initialize(app)` storing `@app`, `def call(env)` returning either `@app.call(env)` or a Rack response triple). No `require` needed — Zeitwerk autoloads `app/middleware/`.

Implement `call(env)` in this exact guard order:

```ruby
class DomainRedirectMiddleware
  def initialize(app)
    @app = app
  end

  def call(env)
    request = ActionDispatch::Request.new(env)
    host = extract_host(request)

    return @app.call(env) if skip_host?(host)

    domain_record = BrokerageDomain
      .where(status: [:active, :phasing_out, :frozen])
      .includes(brokerage: :brokerage_domains)
      .find_by(domain: host)

    return @app.call(env) if domain_record.nil?
    return @app.call(env) if domain_record.is_primary?

    primary = domain_record.brokerage.brokerage_domains.find { |d| d.is_primary? }
    return @app.call(env) if primary.nil?

    redirect_url = "https://#{primary.domain}#{request.fullpath}"
    [301, { "Location" => redirect_url, "Content-Type" => "text/plain" }, ["Moved Permanently"]]
  end

  private

  def extract_host(request)
    origin_host = begin
      URI.parse(request.headers["Origin"].to_s).host&.downcase
    rescue URI::InvalidURIError
      nil
    end
    origin_host.presence || request.host.downcase
  end

  def skip_host?(host)
    main_domain = ENV.fetch("APP_BASE_DOMAIN", "realstate.ca")
    dev_hosts = %w[localhost 127.0.0.1]
    host == main_domain || (Rails.env.development? && dev_hosts.include?(host))
  end
end
```

CRITICAL constraints, do NOT deviate:
- The DB query MUST use `where(status: [:active, :phasing_out, :frozen])` — NOT `BrokerageDomain.routable` (routable excludes frozen, which would break DPRD-02).
- Do NOT add `.without_deleted` — `BrokerageDomain` does not include `acts_as_paranoid` and it would raise NoMethodError.
- Use `.includes(brokerage: :brokerage_domains)` to eager-load, then resolve primary with `.find { |d| d.is_primary? }` on the in-memory collection (no second AR query — prevents N+1 in the per-request hot path).
- Build the redirect URL with `request.fullpath` (not manual PATH_INFO + '?' + QUERY_STRING — that adds a trailing `?` for query-less requests).
- Always guard `primary.nil?` before interpolating `primary.domain`.
- Status 301 (permanent) for all HTTP methods.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client → Rack middleware | Untrusted HTTP request headers (Origin, Host) cross here before any auth runs |
| middleware → database | BrokerageDomain lookup keyed on attacker-supplied host string |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-23-01 | Spoofing | extract_host (Host header injection) | mitigate | Origin-first extraction (Origin is browser-controlled and harder to forge than Host); `ActionDispatch::HostAuthorization` runs before this middleware as a defense-in-depth guard; host is used only as a DB lookup key, never trusted for the redirect target |
| T-23-02 | Tampering | redirect Location header (open redirect) | mitigate | Location target is always `domain_record.brokerage.brokerage_domains.find { |d| d.is_primary? }.domain` — pulled from the DB, never from request input. Attacker-controlled host cannot influence the redirect destination |
| T-23-03 | Denial of Service | infinite redirect loop (A→B→A) | mitigate | A domain that is itself primary always passes through via `is_primary?` guard before any redirect; the redirect target is always the primary, which never redirects — loop is structurally impossible |
| T-23-04 | Input Validation | malformed Origin header | mitigate | `URI.parse(...).host` wrapped in `rescue URI::InvalidURIError → nil`; falls back to `request.host`, never raises |
| T-23-05 | Denial of Service | per-request N+1 DB query in hot path | accept | Mitigated to 2 queries via `.includes(brokerage: :brokerage_domains)` + in-memory `.find`; residual per-request lookup cost is acceptable for current scale (single-tenant-per-domain) |

No high-severity residual threats. All identified threats are mitigated except T-23-05 which is accepted with a documented N+1 mitigation in place.
